## 公開の手順

```bash
bash "/Users/yuriko/Documents/corin/00_🏢 company/projects/_柄ライブラリ/scripts/deploy_web.sh"
```

これ1本で、library.json の再生成 → 書き出しSVGの検証 → main ブランチ確認 → コピー → commit → push まで行います。
**自分で `git add` / `commit` / `push` しないでください**（検証ゲートを飛ばすことになります）。
