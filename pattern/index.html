柄ジェネレーター

柄を選んで、糸の太さ・配色・織り・実寸を決めると、パターン用SVG・A3実寸SVG・リピートイメージ がダウンロードできます

チェック

押すとその柄と配色で開きます。そこから太さも色も直せます。

ドット

押すと並べ方と色が入った状態で開きます。

1. 配色

クリックで色を変えられます。増やす／減らすは右の「糸の並び」で帯を選んでから。

2. 織り

0%＝フラット、100%＝しっかり織り目。強くするほど細い線が破線に見えてきます。

3. 実寸

45度で使うと、丈の方向には柄が約1.41倍おおきく出ます。 A3実寸はこの向きで焼き込んで書き出します（イラレで回さなくてOK）。 パターン用SVGは直交のまま（スウォッチに登録して「パターンの変形」で回す用）。

4. ダウンロード

糸の並び → 1リピート

帯は下の柄と同じ並び。左半分だけ触れます（右半分は鏡うつし）。

1. 柄のSVGを読み込む

ここに .svg をドロップ
（クリックして選んでもOK）

Illustrator から「ファイル > 書き出し > SVG」で出したものが読めます。 ファイルはこのブラウザの中だけで処理されます（どこにも送信しません）。 元のファイルは書き換えません。

2. 配色をまるごと当てる

右の「配色の候補」を押すと、その配色が柄ぜんぶに当たります。

ふだんはオフでOK（案の色がそのまま当たるので、候補の違いがはっきり出ます）。
柄の濃淡が変わって「別の柄」に見えてしまうときだけオンにすると、色味だけ案から取って 濃い／薄いの関係は元のまま保てます。ただし似た候補ばかりに見えるようになります。

3. 色味ごとにまとめて動かす

読み込んだ色を色味で分けました。バーを動かすとその色味の色がまとめて変わります。

4. 1色ずつ直す

明るい順に並べてます
